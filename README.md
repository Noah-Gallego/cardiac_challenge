# Machine Learning for Cardiac Electrophysiology

Notebook implementations for learning cardiac electrophysiology mappings from ECG and simulated intracardiac recordings.

## Overview

The repository contains four task notebooks:

1. `task1ArrhythmiaClassifier.ipynb` — arrhythmia classification.
2. `task2ArrhythmiaMultiClassifier.ipynb` — multiclass arrhythmia classification.
3. `task3ActivationTimePredictor.ipynb` — activation-time prediction.
4. `taskFourCompleteNoah.ipynb` — the fourth task implementation.

`download_intracardiac_dataset.sh` is provided for downloading the intracardiac dataset. The repository also includes `LICENSE` and `NOTICE` files; retain those notices when reusing the work.

## Data and references

The notebooks reference the ECG Heartbeat Categorization Dataset and the Dataset of Simulated Intracardiac Transmembrane Voltage Recordings and ECG Signals. Review the source dataset terms before downloading or redistributing data.

- [ECG Heartbeat Categorization Dataset](https://www.kaggle.com/datasets/shayanfazeli/heartbeat)
- [Simulated intracardiac recordings and ECG signals dataset](https://library.ucsd.edu/dc/object/bb29449106)

## Usage

Review the notebooks in task order and follow their documented dataset and dependency requirements. The repository does not include a root dependency manifest or automated test suite.

This is a research and challenge-project notebook collection. Results depend on the referenced datasets and the execution environment.
